### 易错点记录

（每次编程出错后，在这里记一条：错误现象 + 原因 + 修正方法）

1. 冒泡排序中，未能使所有数字从大到小排序
     for (i = 0; i < 9; i++)
    { /* 最多 9 轮，每轮把一个大的送到右边 */
        for (j = 0; j < 9 - i; j++)
        { /* 后面 i 个已经排好，不用再比
            if (c[j] > c[j + 1])
            { /* 相邻两个比，大的往右换 */
                t = c[j];
                c[j] = c[j + 1];
                c[j + 1] = t;
            }
        }
    }

原因：内层循环未使用j。本质上一次只确定一个数的位置。修正方法：把内层循环中所有i换为j。
外层决定轮数，内层决定一轮中交换几次，符合内外层的逻辑关系。
2.代码中 char nm; 只能存一个字符（实际上是1个字节）。
中文字符在 UTF-8 编码下通常占 3 个字节。用char[50]。
