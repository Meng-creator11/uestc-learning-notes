```bash
./main            # Linux / macOS
.\main.exe        # Windows PowerShell
```

调试版本建议加消毒器（GCC/Clang 可用，部分 MinGW 不支持）：

4. **三问复盘**：边界对吗？异常输入会怎样？如果数据量扩大 100 倍还成立吗？

# 第一阶段：语法打底

## 模块 0 环境、编译与第一个程序

**学习目标**：独立完成「写代码 → 编译 → 运行 → 看报错 → 改对」的完整循环，不再害怕命令行。

**知识速览**

- C 程序从 `main` 开始执行，`return 0;` 表示正常退出。
- 编译四阶段：预处理（`.i`）→ 编译（`.s`）→ 汇编（`.o`）→ 链接（可执行文件）。
- `printf` 不自动换行；`\n` 是换行符，`\t` 是制表符。
- 编译警告不是噪音。`-Wall -Wextra` 打开的警告，九成是真实 bug。

**常见坑**

- 文件名用 `.c` 结尾，`main` 拼成 `mian`。
- 代码里混入中文标点：`；` `，` `（` 都会让编译器报奇怪的错。
- 忘记写 `#include <stdio.h>`，却使用 `printf`。

## 模块 1 变量、数据类型与输入输出

**学习目标**：选对类型、算对精度、输出对齐；理解整数与浮点在计算机中的差别。

**知识速览**

| 类型 | 典型大小 | 用途 | 打印格式 |
| --- | --- | --- | --- |
| `char` | 1 字节 | 字符 / 小整数 | `%c` / `%d` |
| `short` | 2 字节 | 节省空间的小整数 | `%hd` |
| `int` | 4 字节 | 默认整数 | `%d` |
| `long long` | 8 字节 | 大整数 | `%lld` |
| `float` | 4 字节 | 低精度小数 | `%f` |
| `double` | 8 字节 | 默认小数 | `%lf`（`scanf`）/ `%f`（`printf`） |
| `size_t` | 4/8 字节 | 长度、下标 | `%zu` |

**常见坑**

- `5 / 2` 是 `2`，不是 `2.5`；要写成 `5.0 / 2`。
- `scanf("%d", n)` 少写 `&`，程序可能直接崩溃。
- `float` 只有约 7 位有效数字，金额计算建议用整数「分」或 `double`。
- `printf` 的格式符与参数类型不匹配是未定义行为。

### 1-1 温度转换 ★

输入一个摄氏温度（整数），输出华氏温度，保留 1 位小数。公式：`F = C × 9 / 5 + 32`。

```text
输入：36
输出：96.8
```

要求：先用整数运算分别写 `C * 9 / 5 + 32` 和 `C / 5 * 9 + 32`，比较 `37` 的结果；再用 `double` 重写，说明为什么浮点下两者一致。

### 1-2 圆的面积与周长 ★

输入半径 `r`（`double`），输出面积和周长，保留 2 位小数，π 取 `3.14159`。

```text
输入：2.5
输出：area = 19.63, perimeter = 15.71
```

要求：用 `const double PI` 定义常量；再改用 `#define PI 3.14159` 写一版，说明两者区别。

### 1-3 sizeof 探针 ★

不查资料，先预测下列表达式的结果，再写程序验证（用 `%zu` 输出）：

```c

sizeof(long)

sizeof(float)
sizeof(double)

```

思考：`sizeof` 是函数吗？在 `int` 为 4 字节的平台上，`sizeof(int[10])` 为什么等于 40 而不是 10？

### 1-4 整数溢出观察 ★★

```c
#include <limits.h>

```

1. 运行并记录结果；
2. 查 `limits.h`，输出 `INT_MAX`、`INT_MIN`、`LLONG_MAX`；

### 1-5 0.1 + 0.2 真的等于 0.3 吗 ★★

```c
double x = 0.1 + 0.2;
```

## 模块 2 运算符与表达式

**学习目标**：算得对、算得安全；能识别未定义行为和隐式类型转换。

**知识速览**

优先级从高到低（常用部分）：

```text
() [] -> .          ↑ 最高
! ~ ++ -- + - (单目) * & sizeof
* / %
+ -
<< >>
< <= > >=
== !=
&
^
|
&&
||
?: 
= += -= ...          ↓ 最低
```

**常见坑**

- `i = i++ + ++i` 是未定义行为，不同编译器结果不同，永远不要写。
- `a & 1 == 0` 被解析为 `a & (1 == 0)`，要写 `(a & 1) == 0`。
- `if (a = 0)` 是赋值，不是比较。
- 移位位数超过类型宽度是未定义行为。

### 2-1 表达式手算与验证 ★

先手算下列表达式（`int a = 5, b = 2; double c = 2.0;`），再写程序打印验证：

```c
a + b * 3
(a + b) * 3
a / b
a % b
a / c
a * 1.0 / b
-a + b
a > b && b > 0
!a || b
a & b
a | b
a ^ b
a << 1
```

对每个结果写一句解释；凡是有隐式转换的，标出转换发生在哪一步。

### 2-2 拆数字 ★

输入一个三位正整数，输出百位、十位、个位以及它们的和。

```text
输入：365
输出：百位=3 十位=6 个位=5 和=14
```

进阶：不限制位数，倒序输出各位数字（如 `12345` → `54321`），并求位数。

### 2-3 闰年判断 ★

输入年份，输出 `LEAP` 或 `COMMON`。要求用**一个**布尔表达式完成：

```c
(y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)
```

测试：`1900`（平年）、`2000`（闰年）、`2024`（闰年）、`2023`（平年）。再思考：为什么不能只写 `y % 4 == 0`？

### 2-4 位运算入门 ★★

不使用循环和库函数，完成：

1. 判断整数奇偶：`n & 1`；
2. 判断正整数是否为 2 的幂：`n > 0 && (n & (n - 1)) == 0`；
3. 交换两个整数（异或版）；
4. 求 `n` 的绝对值（不用 `if`）：提示 `mask = n >> 31`；
5. 打印一个 `unsigned char` 的 8 位二进制。

```text
输入：10
输出：even
输入：16
输出：power of two
```

### 2-5 自增自减的边界 ★★

先预测，再运行，再解释：

```c
int i = 5;
```

然后回答：下面两条语句为什么"结果不可靠"？给出等价的、行为确定的写法。

```c
int x = 1;

printf("%d\n", x);
```

### 2-6 复合赋值与截断 ★★

```c
c += 1;

```

1. 预测并运行，解释 `i` 为什么是 15 而不是 15.0；
2. `c += 1` 的结果依赖什么？为什么这是"实现定义"而不是"未定义"？
3. 写代码验证 `short s = 40000;` 在常见平台上的输出，并说明如何避免。

### 2-7 三目运算符 ★

1. 输入三个整数，用嵌套三目求最大值；
2. 输入一个整数，输出 `positive` / `zero` / `negative`；
3. 用三目实现 `abs`，并讨论 `x < 0 ? -x : x` 在 `x == INT_MIN` 时的问题。

### 2-8 短路求值 ★★

```c
int a = 10, b = 0;
if (b != 0 && a / b > 2)
    printf("yes\n");
```

1. 解释为什么不会发生除零；

## 模块 3 分支结构

**学习目标**：把现实规则准确翻译成条件；写出可读、可维护的多分支逻辑。

## 模块 4 循环结构

**学习目标**：用循环处理批量数据；能写嵌套循环；知道何时用 `for`、`while`、`do-while`。

**知识速览**

```c
for (初始化; 条件; 更新) 语句;
while (条件) 语句;
do 语句; while (条件);
```

- `for` 适合次数已知；`while` 适合"满足条件就一直做"；`do-while` 至少执行一次。
- `break` 跳出当前层循环；`continue` 跳过本次剩余语句。
- 嵌套循环中 `break` 只跳出内层；需要跳出多层时用标志变量或 `goto`。

**常见坑**

- 循环变量在循环体内被修改，导致次数不对。
- `for (i = 0; i <= n; i++)` 与数组下标 `0..n-1` 混用，造成越界。
- 浮点循环变量累加误差：`for (double x = 0; x != 1; x += 0.1)` 可能死循环。
- `while (getchar() != '\n')` 用于清空输入缓冲区，注意 EOF。

## 模块 5 函数与递归

**学习目标**：把长程序拆成小函数；理解参数传递、作用域、递归的调用栈。

**知识速览**

```c
返回类型 函数名(参数列表);          // 声明（原型）
返回类型 函数名(参数列表) { ... }   // 定义
```

- C 采用**值传递**：函数拿到的是实参的副本；想修改调用者的变量必须传地址。
- 数组作为参数会退化为指针，函数内部拿不到数组长度，必须额外传 `n`。
- 递归必须有终止条件，且每次向终止条件靠近；递归深度受栈空间限制。
- `static` 局部变量只初始化一次，生命周期贯穿整个程序。

**常见坑**

- 函数声明与定义签名不一致（参数类型、`const`）。
- 返回局部数组的地址（函数结束即失效）。
- 递归没有终止条件或重复计算，导致栈溢出或指数级耗时。
- 在头文件里定义函数（而非只声明），多文件时重复定义。

## 模块 7 字符串

**学习目标**：理解 C 字符串的本质是"以 `'\0'` 结尾的字符数组"；能安全地读写、查找、切分。

**知识速览**

## 模块 8 指针基础

**学习目标**：建立"变量有地址、指针存地址"的模型；能读懂 `*`、`&`、`[]`、`->` 的组合。

**知识速览**


## 模块 9 指针进阶与动态内存

**学习目标**：按需分配内存；理解堆与栈的生命周期；能写出不泄漏、不越界的动态数据结构。

**知识速览**

```c
int *a = malloc(n * sizeof *a);   // 未初始化
int *b = calloc(n, sizeof *b);    // 初始化为 0
int *c = realloc(a, m * sizeof *c);
free(c);
```

- `malloc` 失败返回 `NULL`，必须检查。
- `free(NULL)` 安全；重复 `free` 是未定义行为。
- 谁分配谁释放；函数返回堆内存时，调用约定要写清楚。
- `realloc` 可能移动内存，必须用临时指针接收。

**常见坑**

- `malloc(10)` 以为分配了 10 个 `int`（实际 10 字节）。
- `free` 栈上变量或数组名。
- 释放后继续使用（悬空指针）。
- `realloc` 直接覆盖原指针，失败时丢失原地址。

### 9-1 malloc 与 free 基础 ★

1. 分配一个 `int`，赋值并打印，然后 `free`；
2. 分配长度为 `n` 的 `int` 数组，读入、求和、释放；
3. 故意不检查 `malloc` 返回值，讨论 `n` 极大时会发生什么；
4. 用 `sizeof *p` 而不是 `sizeof(int)` 写分配表达式，说明好处。

### 9-2 calloc 与 realloc ★★

1. 用 `calloc` 分配 `n` 个 `int`，验证全部为 0；

4. 说明 `realloc(p, 0)` 的行为（实现定义/已废弃），以及正确做法。

### 9-3 动态数组读入 ★★

### 9-4 动态二维数组 ★★★

## 模块 10 结构体、联合体与枚举

**学习目标**：用自定义类型描述"一个学生、一个日期、一条记录"；理解内存布局与对齐。

**知识速览**

```c
struct Point { double x, y; };
struct Point p = {1.0, 2.0};
struct Point q = {.y = 3.0};        // 指定初始化器，x 为 0
struct Point *ptr = &p;
ptr->x;                              // 等价于 (*ptr).x

typedef struct { int x, y; } Vec2;   // 匿名结构体 + typedef
```

- 结构体可以整体赋值（`p = q;`），但不能用 `==` 比较。
- 结构体传参默认复制整个对象；大结构体应传 `const` 指针。
- `union` 的所有成员共享同一块内存；`enum` 本质是整型常量。

- `scanf("%s", p.name)` 忘记 `p.name` 本身已是数组，不能再加 `&`。
- 结构体里有指针成员时，浅拷贝导致重复释放（深拷贝问题）。
- 用 `memcmp` 比较含填充字节的结构体，结果不可靠。
- 位域的具体布局依赖编译器，不适合跨平台二进制协议。

## 模块 11 文件操作

**学习目标**：把内存中的数据持久化；能安全地打开、读写、定位、关闭文件。

**知识速览**

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) { perror("fopen"); return 1; }
while (fgets(buf, sizeof buf, fp) != NULL) { ... }
fclose(fp);
```

| 模式 | 含义 | 文件不存在时 |
| --- | --- | --- |
| `"r"` | 只读 | 失败 |
| `"w"` | 只写，清空或创建 | 创建 |
| `"a"` | 追加 | 创建 |
| `"r+"` | 读写，不清空 | 失败 |
| `"rb"` / `"wb"` | 二进制读写 | 同上 |

**常见坑**

- 不检查 `fopen` 返回值，后面直接崩溃。
- 文本文件用 `"w"` 打开后忘记 `fclose`，数据可能没落盘。
- `fscanf` 返回值不检查，遇到格式不匹配就死循环。
- `fgets` 与 `fscanf` 混用，换行符残留导致跳过输入。
- 二进制结构体直接 `fwrite`，跨平台/跨编译器不可移植（填充字节、大小端）。

## 模块 13 位运算

**学习目标**：直接操作二进制位；理解掩码、移位、补码；能读懂寄存器风格的代码。

**知识速览**

```c
x & y    // 与：清零/取位
x | y    // 或：置位
x ^ y    // 异或：翻转/交换
~x       // 取反
x << n   // 左移，相当于乘 2^n（无溢出时）
x >> n   // 右移；无符号补 0，有符号负数实现定义
```

- 判断第 `k` 位：`(x >> k) & 1`。
- 置位：`x |= (1u << k)`；清零：`x &= ~(1u << k)`；翻转：`x ^= (1u << k)`。
- `x & (x - 1)` 清除最低位的 1；`x & -x` 取出最低位的 1。
- 移位位数必须小于类型宽度，否则未定义。

**常见坑**

- `1 << 31` 对 `int` 是未定义行为（符号位溢出），应写 `1u << 31`。
- 有符号负数右移是实现定义，不要假设算术右移。
- 位运算优先级低于 `==`、`<`，务必加括号。

### 13-1 统计二进制中 1 的个数 ★★

分别实现三种 `popcount`：

1. 逐位检查：循环 32 次；

要求：对 `0`、`1`、`0xFFFFFFFF`、`0x80000000` 测试；比较三种方法在 1000 万次调用下的耗时（选做）。

### 13-2 2 的幂与最低位 ★★

1. 判断正整数 `n` 是否为 2 的幂：`n > 0 && (n & (n - 1)) == 0`；

3. 求最高位的 1 的位置；

## 模块 14 常用算法

**知识速览**

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 |

| 堆 | O(n log n) | O(n log n) | O(1) | 否 |

```c
{
```

### 答案 14-3：归并排序

```c
#include <stdio.h>
#include <stdlib.h>

static void merge(int a[], int l, int m, int r, int tmp[])
{
    int i = l, j = m + 1, k = l;

    while (i <= m && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= m)
        tmp[k++] = a[i++];
    while (j <= r)
        tmp[k++] = a[j++];

    for (i = l; i <= r; i++)
        a[i] = tmp[i];
}

static void msort(int a[], int l, int r, int tmp[])
{
    if (l >= r)
        return;

    int m = l + (r - l) / 2;
    msort(a, l, m, tmp);
    msort(a, m + 1, r, tmp);
    merge(a, l, m, r, tmp);
}

int merge_sort(int a[], int n)
{
    if (n <= 1)
        return 0;

    int *tmp = malloc((size_t)n * sizeof *tmp);
    if (tmp == NULL)
        return -1;

    msort(a, 0, n - 1, tmp);
    free(tmp);
    return 0;
}
```

要点：`m = l + (r - l) / 2` 避免 `l + r` 溢出；`<=` 保证稳定；临时数组只分配一次，递归中复用；合并后必须写回原数组。

```c
        prev = head;
        head = next;
    }

{

}
```

### 答案 15-9：二叉树

```c
#include <stdlib.h>

    int value;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *insert(TreeNode *root, int v)
{
    if (root == NULL) {
        TreeNode *n = malloc(sizeof *n);
        if (n == NULL)
            return NULL;
        n->value = v;
        n->left = n->right = NULL;
        return n;
    }
    if (v < root->value)
        root->left = insert(root->left, v);
    else if (v > root->value)
        root->right = insert(root->right, v);
    return root;
}

static void inorder(const TreeNode *root)
{
    if (root == NULL)
        return;
    inorder(root->left);
    printf("%d ", root->value);
    inorder(root->right);
}

static int height(const TreeNode *root)
{
    if (root == NULL)
        return 0;
    int l = height(root->left);
    int r = height(root->right);
    return 1 + (l > r ? l : r);
}

static void free_tree(TreeNode *root)
{
    if (root == NULL)
        return;
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

int main(void)
{
    int values[] = { 50, 30, 70, 20, 40, 60, 80 };
    TreeNode *root = NULL;

    for (size_t i = 0; i < sizeof values / sizeof values[0]; i++)

    putchar('\n');
    printf("height=%d\n", height(root));

    free_tree(root);
    return 0;
```

### 答案 16-5：安全整数运算

```c

}
```

要点：加法在运算前检查；乘法先提升到更宽类型再检查；`INT_MIN / -1` 也是溢出，需要单独处理；不要依赖"溢出后回绕"。

# 附录 B：编译与运行时错误速查

| 现象 / 报错关键词 | 常见原因 | 排查方向 |
| --- | --- | --- |
| `expected ';' before ...` | 上一条语句漏分号 | 看报错行的**上一行** |
| `'printf' was not declared in this scope` | 缺 `#include <stdio.h>` | 补头文件 |
| `implicit declaration of function 'sqrt'` | 缺 `<math.h>`，或链接缺 `-lm` | 补头文件；Linux 加 `-lm` |
| `undefined reference to 'foo'` | 只有声明没有定义，或没链接对应 `.o` | 检查是否编译/链接了实现文件 |
| `multiple definition of 'x'` | 头文件里定义了变量/函数 | 头文件只放 `extern` 声明，定义放 `.c` |
| `redefinition of 'struct X'` | 头文件重复包含，缺 include guard | 加 `#ifndef/#define/#endif` |
| `warning: control reaches end of non-void function` | 非 `void` 函数缺 `return` | 所有路径都要返回值 |
| `format '%d' expects int, but argument has type 'double'` | 格式符与参数类型不匹配 | 对照类型表改正 |
| `Segmentation fault` | 空/野指针、数组越界、栈溢出、`scanf` 缺 `&` | 用 gdb 看 `bt`，或 ASan |
| `stack smashing detected` | 栈数组越界写坏了 canary | 检查所有数组下标与 `strcpy` |
| `free(): double free detected` | 同一指针释放两次 | 释放后置 `NULL`，理清所有权 |
| `malloc(): corrupted top size` | 堆缓冲区越界写 | ASan 定位越界位置 |
| `AddressSanitizer: heap-use-after-free` | 释放后继续使用 | 释放后置 `NULL`，检查生命周期 |
| `AddressSanitizer: memory leak` | 分配后未释放 | 每个成功 `malloc` 都要有 `free` |
| 程序卡住、无输出 | 死循环；`scanf` 等输入；输出缓冲区未刷新 | 检查循环条件；加 `fflush(stdout)` |
| 中文输出乱码 | 源文件编码与控制台代码页不一致 | 统一 UTF-8，或 Windows 下 `chcp 65001` |
| `ld returned 1 exit status` | 链接阶段失败的总提示 | 往上看第一条具体错误 |
| `undefined reference to 'WinMain'` | MinGW 按 GUI 子系统链接，找不到 `main` | 加 `-mconsole`，或检查 `main` 拼写 |

# 附录 D：术语表

| 中文 | 英文 | 一句话解释 |
| --- | --- | --- |
| 预处理 | preprocessing | 编译前展开 `#include`、`#define`、条件编译 |

| 回调 | callback | 把函数指针传给别的函数，由后者择机调用 |

**三条建议**

1. **每道题都自己先写 20 分钟**，再看答案；看懂不等于会写。
2. **每个 bug 都记一句话**：现象、原因、修法。三个月后这就是你的经验库。
3. **每完成一个模块，回头重写一遍最难的题**，不看旧代码。能复现，才算真的会。

> 学习的终点不是"刷完这些题"，而是面对一个新需求时，你能自然地说出：数据结构选什么、边界在哪里、内存谁负责、怎么验证它是对的。
