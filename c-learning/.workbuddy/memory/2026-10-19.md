## 新建 C 语言练习题库（practice/）

- 位置：`practice/`，共 11 个 md 文件、约 7000 行。
- 结构：`README.md`（总目录 + 进度追踪）+ 01~09 九个模块（254 题）+ 10 综合实战（13 个项目）。
- 模块顺序：基础语法 → 分支 → 循环 → 函数与递归 → 数组 → 字符串 → 指针 → 结构体 → 文件与动态内存 → 综合。
- 每模块统一结构：知识点自查 → A/B/C 三组题（★/★★/★★★）→ 易错点速查表 → 通关标准 → 仅选择题/读程序题的参考答案。
- 设计原则：**编程题一律不给参考代码**，只给样例输入输出、验收标准、思路提示。符合用户"拒绝 AI 代写代码"的明确要求。
- 难度对齐用户进度：01–04 为复习（已学完），05–06 为当前学习重点，07–09 为后续，10 收尾。
- 编译命令沿用用户既有约定：`gcc -Wall -fexec-charset=GBK`。
