# c-learning 项目长期记忆

## 仓库定位

电子科技大学计算机专业（2026 年 8 月入学）的 C 语言学习笔记仓库，目标是打牢基础、为保研做准备。

## 目录约定

- `array/`、`string/`：可**单独编译运行**的示例程序，每个文件一个 `main`，文件名 `01_xxx.c` 递增
- `practice/`：练习题库，`README.md` 为总目录，`01_`~`10_` 为分模块文件
- 根目录：`*_学习指南.md` 为准教材式长文（表格 + 内存图 + 易错点速查 + 自测清单）

## 硬性约定

1. **不给编程题参考代码**。用户明确拒绝 AI 代写代码，练习材料只给样例、提示、验收标准；仅选择题/读程序题提供答案。
2. 源码统一 **UTF-8（无 BOM）**，不要另存 GBK。
3. 编译命令固定带 `-Wall -fexec-charset=GBK`（用户 VS Code Code Runner 已配好）。
4. 教材与考试导向：数组长度用 `#define` 常量，不推崇 VLA。
5. 练习题的样例数据**必须自己核算**，不写"大概对"的数字。

## 写作风格

- 中文，第三人称直接讲，不用"亲""宝子"这类词
- 每题带"必须回答"的追问，逼读者想清楚而不是照抄
- 易错点用表格，每条给出「错误写法 / 后果 / 正确写法」
- 重要结论用一句话总结，可背诵
