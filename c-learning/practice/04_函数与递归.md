## 开始前：知识点自查

- [ ] 函数三要素：**返回类型、函数名、参数列表**
- [ ] 声明（原型）和定义的区别，为什么 `main` 之前要先声明
- [ ] C 语言参数是**值传递**：函数里改形参，不影响实参
- [ ] 数组作参数会退化成指针，所以必须**额外传长度**
- [ ] 递归必须有两个东西：**递归关系** + **终止条件**
- [ ] `return` 一个值；想返回多个，要靠指针（第 07 章）

## A 组 · 函数基础（1–8）

### 1. 第一个函数 ★

**要求**：写一个函数 `int max2(int a, int b)`，返回较大值。在 `main` 里读入两个数，调用它并输出。

**样例输入/输出**
```
3 9  -> 最大值: 9
```

**必须做到**：
1. 函数定义写在 `main` **之前**（或先写原型）
2. `main` 里**不再有比较逻辑**，只负责输入、调用、输出

**这一步是习惯问题**：`main` 应该只做"流程"，具体计算交给函数。

### 4. 交换函数（最经典的坑） ★★

**要求**：先写下面这个函数，在 `main` 里调用它交换两个数，观察结果；然后修好它。

```c
void swap(int a, int b)
{
    int t = a;
    a = b;
    b = t;
}
```

**必须回答**：
1. 为什么 `main` 里的两个数**没变**？
2. `swap` 里面的 `a`、`b` 和 `main` 里的 `a`、`b` 是同一个东西吗？
3. 怎么才能真的交换？（写出正确版本）

**提示**：正确版本需要指针：`void swap(int *a, int *b)`，调用时 `swap(&x, &y)`。指针第 07 章才细讲，但这题**现在就要理解"值传递"**。

**用一句话总结**：函数拿到的是**复印件**，改复印件不影响原件。

### 8. 三件套重构 ★★★

## B 组 · 递归入门（9–20）

> **递归的写法模板**（所有递归题都是这个形状）：
> ```c
> 返回类型 f(参数)
> {
>     if (终止条件) return 终止值;     /* ① 出口，必须有 */
>     return 用 f(规模更小的参数) 算;  /* ② 递归，必须变小 */
> }
> ```
> 写不出来时，就问自己两句话：**"什么时候停？"** 和 **"大问题怎么变成小问题？"**

### 13. 汉诺塔 ★★★

**要求**：读入盘子数 `n`，输出移动步骤和总步数。

**样例输入/输出（n = 3）**
```
A -> C
A -> B
C -> B
A -> C
B -> A
B -> C
A -> C
共 7 步
```

**要求**：写 `void hanoi(int n, char from, char to, char via)`。

**必须回答**：
1. 把 `n` 个盘子从 A 移到 C，**第一步必然是**什么？（把上面 `n-1` 个移到 B）
2. 步数公式是 `2^n - 1`，用递推验证一下
3. `n = 20` 时要多少步？`n = 64` 呢？（后者是传说中"世界末日"那个数）

**这题是递归思想的典范**：不关心细节，只关心"把 `n-1` 个当成一个整体"。

## C 组 · 作用域、存储类别与进阶（21–28）

### 21. 读程序：三种变量 ★★

**要求**：写出输出，再运行验证。

```c
#include <stdio.h>

int g = 10;

void f(void)
{
    int a = 1;
    static int s = 1;
    a++;
    s++;
    printf("f: a=%d, s=%d, g=%d\n", a, s, g);
}

int main(void)
{
    int i;
    for (i = 0; i < 3; i++) {
        int a = 100;
        f();
        printf("main: a=%d\n", a);
    }
    return 0;
}
```

**必须回答**：
1. `a`（局部）为什么每次都是 2？
2. `s`（静态局部）为什么每次加 1？
3. 循环里的 `int a = 100;` 和 `f` 里的 `int a` 是同一个变量吗？
4. 全局变量 `g` 如果被 `f` 修改了会怎样？（改一下试试）

**必须记住**：`static` 局部变量**只初始化一次**，之后一直存在——它是"有记忆的局部变量"。

### 28. 综合：用函数重构一个完整程序 ★★★

**要求**：把第 03 章第 35 题（打印日历）重构成函数版本：

3. 没有重复的 `switch` 分支（月份天数只在一个地方写）
4. 换一行命令就能编译通过，`-Wall` 零警告

**这就是"可维护"的含义**：不是能跑就行，而是**改一个需求只需要改一个地方**。

## 参考答案（仅读程序题）

**第 21 题**
```
f: a=2, s=2, g=10
main: a=100
f: a=2, s=3, g=10
main: a=100
f: a=2, s=4, g=10
main: a=100
```
- `a` 是普通局部变量，每次进函数重新创建、重新赋 1，所以永远打印 2
- `s` 是 `static`，只初始化一次，之后一直累加
- 循环里的 `a` 和 `f` 里的 `a` 是两个完全无关的变量（不同作用域）

**第 5 题的答案**：`sizeof(a)` 在函数内得到的是**指针的大小**（64 位系统通常是 8），不是数组总字节数。因为数组作参数会退化成指针。
