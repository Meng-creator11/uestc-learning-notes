# 02 · 分支结构

> **前置知识**：01 章
> **题量**：25 题（A 组 10 / B 组 10 / C 组 5）
> **目标**：写分支时不再"漏情况"。分支的难点从来不是 `if` 的语法，而是**边界条件和情况穷举**。

---

## 开始前：知识点自查

- [ ] `if (x = 0)` 和 `if (x == 0)` 的区别，为什么前者永远不执行
- [ ] 知道 `&&`、`||` 的**短路求值**：`if (p != NULL && p->x > 0)` 为什么安全
- [ ] 浮点数不能直接和 0 比较（用 `fabs(x) < 1e-9`）
- [ ] `switch` 的 `case` 只能是**整型常量**，不能是范围、不能是浮点
- [ ] 知道 `else` 永远和**最近的、未配对的 `if`** 配对

## A 组 · 单条件与双分支（1–10）

### 1. 奇偶判断 ★

**要求**：读入一个整数，输出它是奇数还是偶数（包括负数）。

**样例输入**
```
-7
```
**样例输出**
```
-7 是奇数
```

**要求**：写两个版本——一个用 `% 2`，一个用 `& 1`。**说明哪个版本对负数也天然正确。**

**提示**：`-7 % 2` 在 C 语言里是 `-1`，不是 `1`。所以 `n % 2 == 1` 会误判负数，正确写法是 `n % 2 != 0`。

---

### 2. 闰年判断 ★★

**要求**：读入年份，判断是否闰年。

**规则**：能被 4 整除但不能被 100 整除，**或者**能被 400 整除。

**样例输入/输出**
```
2024  ->  2024 是闰年
1900  ->  1900 不是闰年
2000  ->  2000 是闰年
```

**要求写出 3 种等价写法**：
1. 用 `&&` `||` 组合
2. 用嵌套 `if`
3. 用三目运算符

**这题必须做到一次对**：它是后面所有日期类题目的地基。测试用例请一定包含 `1900`、`2000`、`2023`、`2024`。

---

### 3. 三个数的最大值 ★

**要求**：读入三个整数，输出最大值。**不许用数组**（数组下一章才学）。

**样例输入**
```
3 9 5
```
**样例输出**
```
最大值: 9
```

**要求写两个版本**：
1. 擂台法：先假设 `max = a`，再依次比较
2. 两两比较法：先比 `a`、`b`，再和 `c` 比

**思考**：如果三个数都是负数，擂台法初始化成 `max = 0` 会怎样？这是第 05 章"求最值"的同一个坑。

---

### 4. 绝对值与符号 ★

**要求**：读入一个实数，输出它的绝对值，并判断它是正数、负数还是零。**绝对值部分必须用三目运算符 `? :` 写。**

**样例输入**
```
-2.5
```
**样例输出**
```
|-2.5| = 2.50
-2.5 是负数
```

**提示**：`x >= 0 ? x : -x`。判断"是不是零"要用 `fabs(x) < 1e-9`，别用 `x == 0`。

---

### 5. 能否构成三角形 ★

**要求**：读入三个正实数，判断能否构成三角形。

**样例输入/输出**
```
3 4 5   -> 能构成三角形
1 2 5   -> 不能构成三角形
```

**要求**：不只判"任意两边之和大于第三边"，还要处理"输入了非正数"。

**提示**：三个条件都要满足。或者用"两小边之和 > 最大边"的等价写法——哪个更好写？

---

### 6. 三角形类型判断 ★★

**要求**：在上一题基础上，输出三角形的类型：等边、等腰、直角、普通。

**样例输入/输出**
```
3 3 3    -> 等边三角形
3 3 4    -> 等腰三角形
3 4 5    -> 直角三角形
4 5 6    -> 普通三角形
```

**必须考虑**：
1. 等腰直角三角形（如 `1 1 sqrt(2)`）该归哪类？**先定规则再写代码**，把规则写在注释里。
2. 直角判断不能用 `a*a + b*b == c*c`（浮点误差），要用差值比较。

**这题的重点是"分类规则本身有歧义"** —— 实际开发中你经常要先跟需求方确认规则，再动手。

---

### 7. 分段函数 ★★

**要求**：读入 `x`，按下面的分段函数求 `y`，输出保留 2 位小数。

```
y = x        (x < 0)
y = 2x + 1   (0 <= x < 5)
y = x * x    (5 <= x < 10)
y = 3x - 2   (x >= 10)
```

**样例输入/输出**
```
-3   -> y = -3.00
0    -> y = 1.00
7    -> y = 49.00
12   -> y = 34.00
```

**必须测试的边界**：`x = 0`、`x = 5`、`x = 10`。写出这三个点应该落在哪个区间（看上面的定义，注意 `<` 和 `<=`）。

---

### 8. 字符类型判断 ★★

**要求**：读入一个字符，输出它属于哪一类：大写字母、小写字母、数字、空格、其他。

**样例输入/输出**
```
A   -> 大写字母
a   -> 小写字母
7   -> 数字
(空格) -> 空格
@   -> 其他字符
```

**提示**：用 `c >= 'A' && c <= 'Z'` 这种写法。**别写 `c >= 65 && c <= 90`** —— 后者虽然对，但三个月后你自己都看不懂。

**进阶**：想想"如果输入的是中文的第一个字节会怎样"？（提示：`char` 可能是负数，`isalpha` 之类的库函数对负数有未定义行为。）

---

### 9. 大小写转换 ★

**要求**：读入一个字符，如果是小写字母转成大写，大写转成小写，其他字符原样输出。

**样例输入/输出**
```
a  -> A
G  -> g
5  -> 5
```

**要求**：用三目运算符写成**一行**。

**提示**：`c >= 'a' && c <= 'z' ? c - 32 : ...` —— 但更清楚的写法是 `c - 'a' + 'A'`。哪种更好？为什么？

---

### 10. BMI 分类 ★★

**要求**：读入身高（米）和体重（千克），算 BMI 并分类。

```
BMI < 18.5        偏瘦
18.5 <= BMI < 24  正常
24 <= BMI < 28    偏胖
BMI >= 28         肥胖
```

**样例输入/输出**
```
1.75 70  -> BMI = 22.86，正常
```

**注意**：分类的边界 18.5 / 24 / 28 要落在哪边？用 `<` 还是 `<=`？**自己定，但要统一，且让 `18.5` 只落进一类。**

## B 组 · 多分支与嵌套（11–20）

### 11. 成绩等级（if 链） ★★

**要求**：读入百分制成绩（0–100 的整数），输出等级。

```
90-100: A
80-89 : B
70-79 : C
60-69 : D
0-59  : E
```

**必须处理非法输入**：小于 0 或大于 100，输出 `成绩不合法`。

**样例输入/输出**
```
95  -> A
59  -> E
101 -> 成绩不合法
```

**提示**：`if-else if` 链的顺序很重要。**从大到小判断**，写起来最简单。想一想：如果从 60 开始往上写，会怎样？

---

### 12. 读程序：悬空 else ★★

**要求**：先写出输出，再运行验证。

```c
int a = 1, b = 2;
if (a > 0)
    if (b > 5)
        printf("A\n");
else
    printf("B\n");
```

**必须回答**：
1. 这个程序输出什么？
2. 那个 `else` 到底和哪个 `if` 配对？
3. 如果想让 `else` 和**外层** `if` 配对，该怎么改？（只加一对花括号）

**这题的价值**：以后看到"缩进看起来对，逻辑却不对"的代码，第一时间数花括号。

---

### 13. 一元二次方程 ★★★

**要求**：读入 `a b c`，解方程 `ax² + bx + c = 0`，输出实根（保留 2 位小数）。

**必须覆盖全部情况**：
1. `a == 0`：退化成一次方程（`b == 0` 时又要分情况）
2. 判别式 `Δ > 0`：两个不等实根
3. `Δ == 0`：两个相等实根
4. `Δ < 0`：无实根

**样例输入/输出**
```
1 -5 6   -> x1 = 3.00, x2 = 2.00
1 2 1    -> x1 = x2 = -1.00
1 0 1    -> 无实根
0 2 4    -> 一次方程, x = -2.00
0 0 5    -> 无解
```

**提示**：`Δ` 判断要用 `fabs(delta) < 1e-9` 判等。**这题最容易漏 `a == 0`**，漏了就是除以零。

**问自己**：`a` 很接近 0（比如 `1e-20`）算不算 0？现实中的数值计算没有绝对的黑白。

---

### 14. 判断回文数（三位数） ★★

**要求**：读入一个三位整数，判断它是否回文（正着读和倒着读一样）。

**样例输入/输出**
```
121  -> 是回文数
123  -> 不是回文数
```

**提示**：拆出百位和个位比较即可。中间那位不用管。

**进阶提问**：如果改成"任意位数的整数"，这题还能只靠 `if` 做吗？—— 不能，这就引出第 03 章的循环。

### 15. 出租车计费 ★★

**要求**：读入行驶里程（公里，可能是小数），计算车费。

```
起步价 10 元（含 3 公里）
3 公里以上：每公里 2.4 元
超过 10 公里的部分：每公里加收 50% 空驶费（即 3.6 元/公里）
```

**样例输入/输出**
```
2.5  -> 车费 10.00 元
5    -> 车费 14.80 元
12   -> 车费 34.00 元
```

**提示**：分三段累加。**先把公式在纸上推导一遍再去写代码**，别边写边想。

**必须测试**：`2.9`、`3.0`、`3.1`、`10.0`、`10.1` 这五个边界值。

### 16. 快递运费 ★★

**要求**：读入重量（千克）和是否加急（`1` 加急 / `0` 不加急），计算运费。

```
首重 1 公斤 12 元
续重每公斤 8 元（不足 1 公斤按 1 公斤算）
加急费 5 元
```

**样例输入/输出**
```
1.2 0  -> 20.00 元
2.0 1  -> 25.00 元
```

**提示**："不足 1 公斤按 1 公斤算"意味着要**向上取整**。`ceil()` 需要 `#include <math.h>`，编译时可能要加 `-lm`。

**或者**：不用 `ceil`，用整数运算和取余实现。哪种更稳？

### 17. 日期合法性 ★★

**要求**：读入 `年 月 日`，判断这个日期是否合法。

**必须覆盖**：
- 月份 1–12
- 每月天数（1/3/5/7/8/10/12 为 31 天，4/6/9/11 为 30 天，2 月看闰年）
- 年份为 0 或负数

**样例输入/输出**
```
2024 2 29  -> 合法
2023 2 29  -> 不合法
2024 4 31  -> 不合法
2024 13 1  -> 不合法
```

**提示**：用一个数组存每月天数 `int days[] = {31,28,31,...}` 会很好写——但数组还没学。**现在先用 `switch` 硬写，等学完数组回来重写一遍，你会感受到差别。**

### 18. 三个数排序 ★★

**要求**：读入三个整数，按从小到大输出。**只许用 `if` 和交换，不许用数组，不许用 `qsort`。**

**样例输入/输出**
```
3 1 2  -> 1 2 3
```

**提示**：三条 `if`：`if (a>b) swap(a,b); if (a>c) swap(a,c); if (b>c) swap(b,c);`
先想清楚为什么这样三句就够，再动手。

**进阶**：如果是五个数呢？—— 手动写会疯掉，这就是为什么要学排序算法（第 05 章）。

### 19. 读程序：忘写 break ★★

**要求**：先写输出，再运行。

```c
int x = 2;
switch (x) {
    case 1: printf("one ");
    case 2: printf("two ");
    case 3: printf("three ");
    case 4: printf("four "); break;
    default: printf("other ");
}

int y = 9;
switch (y / 3) {
    case 3: printf("A");
    case 2: printf("B"); break;
    case 1: printf("C");
}
```

**必须回答**：
1. 两段分别输出什么？
2. 第二段为什么能进 `case 3`？`y / 3` 等于几？
3. `switch` 的 `case` 后面**不写 `break` 会继续往下执行**——这个特性什么时候反而是有用的？（提示：看第 23 题）

**样例输入/输出**

0  -> 你出 石头，电脑出 剪刀，你赢了
1  -> 平局
2  -> 你输了

## C 组 · switch 与综合（21–25）

### 21. 成绩等级（switch 版） ★★

**要求**：用 `switch` 重写第 11 题，**不许使用 5 个 `case 90 ... case 100` 的罗列**。

**样例输入/输出**
```
95  -> A
60  -> D
```

**提示**：`score / 10` 能把 90–99 都变成 9。但 `100 / 10 = 10`，这是个越界的特殊情况，**必须单独处理**。另外 0–59 有 6 种情况，用 `default` 兜住最省事。

**这题是经典考题**：教材上必有，考试必考。做完请把"100 分要特判"写在便利贴上。

---

### 22. 四则运算计算器 ★★★

**要求**：读入 `操作数1 运算符 操作数2`，输出结果。

**样例输入/输出**
```
6 + 3   -> 6 + 3 = 9.00
6 / 4   -> 6 / 4 = 1.50
6 / 0   -> 除数不能为 0
6 % 0   -> 除数不能为 0
6 ^ 3   -> 不支持的运算符
6 x 3   -> 不支持的运算符
```

**要求**：
1. 支持 `+ - * / %`，其中 `%` 要求两个操作数都是整数，否则报错
2. 除零要拦住，**不能让程序崩**（浮点除零会得到 `inf`，整数除零直接崩）
3. 结果保留 2 位小数
4. 用 `switch` 分发，`default` 处理非法运算符

**额外要求（重要）**：允许用户**连续计算**，输入 `q` 退出。这需要循环——现在写不出来没关系，**先写成只算一次，把 `switch` 写对**，第 03 章学完循环回来加。

---

### 23. 某天是这一年的第几天 ★★★

**要求**：读入 `年 月 日`，输出这一天是这一年的第几天。

**样例输入/输出**
```
2024 3 1  -> 2024 年 3 月 1 日是第 61 天
2023 3 1  -> 2023 年 3 月 1 日是第 60 天
```

**要求**：用 `switch` 的"穿透"特性实现——**`case 12` 一直往下落到 `case 1`，累加天数**。

**提示**：
```c
switch (month - 1) {
    case 11: days += 30;   /* 11 月的天数 */
    case 10: days += 31;
    ...
    case 0: break;
}
```
然后在 3 月之后补上闰年的 1 天。

**必须回答**：这里为什么**故意不写 `break`**？和第 19 题对比，体会"同一个语法特性，用对了是技巧，用错了是 bug"。

### 24. 元音判断与统计 ★★

**要求**：读入一个字符，判断它是不是元音字母（`a e i o u`，大小写都算）。要求用 `switch` 实现，且**写法要短**。

**样例输入/输出**
```
a  -> a 是元音
E  -> E 是元音
z  -> z 不是元音
```

**提示**：`case 'a': case 'A': case 'e': case 'E': ...` 多个 `case` 共用一个分支，这也是穿透的用法。

**进阶**：如果输入不是字母，要单独提示。

### 25. 综合：工资计算 ★★★

**要求**：读入员工的工作时长（小时）、每小时工资、以及是否正式员工（`1`/`0`），计算实发工资。

**规则**：
```
基本工资 = 工时 × 时薪
工时 <= 40：无加班费
工时 >  40：超出部分按 1.5 倍计算
正式员工：基本工资 + 500 元岗位津贴
非正式员工：基本工资，且不享受加班费（但按 1.0 倍计）
个人所得税：
    应纳税所得额 = 工资 - 5000
    <= 0      : 不缴税
    0 - 3000  : 3%
    3000-12000: 10%，速算扣除 210
    > 12000   : 20%，速算扣除 1410
```

**样例输入/输出**
```
45 100 1  -> 基本工资 4750.00, 津贴 500.00, 应税 250.00, 个税 7.50, 实发 5242.50
40 200 0  -> 基本工资 8000.00, 津贴 0.00, 应税 3000.00, 个税 90.00, 实发 7910.00
```

**提示**：
1. 先把"基本工资"算清楚，再算税，**分步输出中间结果**便于调试
2. 超额部分：`40×100 + 5×150 = 4750`，不是 `45×150`
3. 税率是累进的，用速算扣除数能一步算出来：`税 = 应税 × 税率 - 速算扣除`
4. 注意第二条样例：`8000 - 5000 = 3000`，正好落在 3% 档的上边界，按 `<= 3000` 处理

**先手算，再编程**。两个样例的中间结果都算对，代码才有可能对。

## 易错点速查

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `if (x = 0)` | 赋值成功，条件为假 | `if (x == 0)` |
| 2 | 浮点 `if (x == 0.0)` | 判不出来 | `fabs(x) < 1e-9` |
| 3 | `if (a < b < c)` | 变成 `(a<b) < c`，恒真 | `a < b && b < c` |
| 4 | `else` 悬空 | 逻辑挂到内层 `if` | 加 `{}` |
| 5 | `case` 忘 `break` | 继续往下执行 | 除故意穿透外都加 |
| 6 | `switch` 用浮点/范围 | 编译错误 | 先转成整型，用整除 |
| 7 | 100 分用 `score/10` | 得 10，越界 | 单独 `case 10` 或特判 |
| 8 | 负数取余 `n%2==1` | 误判为偶数 | `n%2 != 0` |
| 9 | 分类边界重复/遗漏 | 某值落进两类或没有类 | 画数轴，只写 `<` 或 `<=` 一种 |
| 10 | 除零没拦 | 整数除零直接崩 | 先判 `b == 0` |
