# 05 · 数组与二维数组

> **前置知识**：01–04 章
> **题量**：32 题（A 组 16 / B 组 10 / C 组 6）
> **目标**：把"遍历 + 下标"练成本能，并拿下排序、查找、增删这几个高频套路。
> **配套**：本章和你的 `array/` 目录三个文件（`01_array_basics.c` ~ `03_two_dim_array.c`）是同一套知识，可以先跑代码再做题，也可以先做题再对照。

---

## 开始前：知识点自查

- [ ] 下标从 0 开始，长度 `n` 的合法下标是 `0 ~ n-1`
- [ ] `int a[5] = {1,2};` 后两个元素是 0（不是随机值）
- [ ] `int a[10];` 不初始化时里面是**垃圾值**
- [ ] 数组长度必须是**常量表达式**，不能是变量（教材和考试的要求）
- [ ] 数组作函数参数时，必须**额外传长度**
- [ ] 二维数组 `int g[3][4]` 的第二维必须写，第一维可以省

**本章的一条铁律**：每写一个循环，先问自己「`i` 从几开始、到几结束」。数组题 90% 的 bug 都在这里。

## A 组 · 一维数组（1–16）

### 1. 输入与输出 ★

**要求**：读入 `n`（≤ 100）和 `n` 个整数，先正序输出，再逆序输出。

**样例输入/输出**
```
5
1 2 3 4 5
-> 正序: 1 2 3 4 5
-> 逆序: 5 4 3 2 1
```

**要求**：逆序输出用**倒着遍历**实现，**不许修改数组**。

**提示**：`for (i = n - 1; i >= 0; i--)`。注意 `i` 是 `int`，`i >= 0` 能正常结束；如果 `i` 是 `unsigned`，`i >= 0` 永远成立 → 死循环。

---

### 2. 逆置（真的改数组） ★★

**要求**：把数组原地逆置，然后输出。

**样例输入/输出**
```
5
1 2 3 4 5
-> 逆置后: 5 4 3 2 1
```

**要求**：用首尾双指针交换，**只遍历一半**。

**提示**：
```c
int i = 0, j = n - 1;
while (i < j) { 交换 a[i], a[j]; i++; j--; }
```

**必须回答**：如果循环条件写成 `i <= n / 2` 会怎样？`i < n / 2` 呢？三个版本分别试一下，哪个对？

---

### 3. 统计三件套 ★

**要求**：读入 `n` 个整数，输出：总和、平均值（保留 2 位）、最大值及下标、最小值及下标。

**样例输入/输出**
```
5
3 9 1 9 2
-> 和 24，平均 4.80
-> 最大 9 (下标 1)，最小 1 (下标 2)
```

**必须注意**：
1. `max = a[0]`，不能是 0
2. 平均值 `(double)sum / n`，不能是 `sum / n`

---

### 4. 分数段统计 ★★

**要求**：读入 `n` 个成绩（0–100），统计各分数段人数：`0-9, 10-19, ..., 90-99, 100`，共 11 段。

**样例输入/输出**
```
10
85 92 78 100 60 55 92 88 45 100
-> 0-9:   0
-> 10-19: 0
...
-> 90-99: 2
-> 100:   2
```

**要求**：用**桶**的思想：`cnt[score / 10]++`，但 100 分要单独处理。

**提示**：数组开 11 个，`cnt[10]` 专门放 100 分。写 `if (score == 100) cnt[10]++; else cnt[score/10]++;`

**必须回答**：如果不特判 100 分，`cnt[score/10]` 会发生什么？（越界写入，可能改掉别的变量——这是最阴险的 bug 之一。）

---

### 5. 线性查找 ★★

**要求**：读入 `n` 个数和一个目标值 `x`，输出 `x` 第一次出现的下标；找不到输出 `-1`。

**样例输入/输出**
```
5
3 9 1 9 2
9  -> 下标 1
7  -> -1
```

**要求**：
1. 找到就 `break`，不要继续找
2. 找不到的判断不能写在循环体里（否则每个不等于的都输出一次）

**提示**：用一个变量 `pos = -1`，循环里找到了就 `pos = i; break;`，循环后统一输出。

---

### 6. 删除元素 ★★★

**要求**：读入 `n` 个数，再读入要删除的值 `x`，删除**所有**等于 `x` 的元素，输出剩余元素和新的长度。

**样例输入/输出**
```
6
1 2 3 2 4 2
2
-> 剩余 3 个: 1 3 4
```

**要求**：不得使用额外数组，**原地**完成。

**提示**：用"双指针写入"：`j` 指向下一个该写的位置，遍历 `i`，不等于 `x` 就 `a[j++] = a[i]`。最后新长度就是 `j`。

**必须回答**：为什么不能写成"找到就往前搬"？（那样每次搬都要循环，变成 `O(n²)`，而且连续相邻的 `x` 会漏删。你试试删 `1 2 2 3` 里的 `2`。）

---

### 7. 有序插入 ★★★

**要求**：读入 `n` 个**已升序**的数，再读入一个 `x`，把 `x` 插入后数组依然有序，输出结果。

**样例输入/输出**
```
5
1 3 5 7 9
4
-> 1 3 4 5 7 9
```

**要求**：从后往前找位置，边找边把元素后移（不要找到位置再整体搬）。**注意数组要预留空间**（开 101 个，只用 n 个）。

**提示**：
```c
int i = n - 1;
while (i >= 0 && a[i] > x) { a[i+1] = a[i]; i--; }
a[i+1] = x;
n++;
```
先想清楚 `i` 走到 `-1` 时 `a[0]` 怎么处理。

---

### 8. 数组去重 ★★★

**要求**：删除数组中重复的元素，**保留第一次出现的顺序**。

**样例输入/输出**
```
7
3 1 3 2 1 5 2
-> 3 1 2 5
```

**要求**：不许用额外数组（或者允许用，但要说明空间复杂度）。

**提示**：双重循环：外层遍历，内层检查"这个数在前面是否已经出现过"。

**进阶**：如果数组是有序的，去重可以一层循环搞定。为什么？（因为重复的必然相邻。）

---

### 9. 合并两个有序数组 ★★★

**要求**：读入两个**升序**数组，合并成一个升序数组。

**样例输入/输出**
```
3
1 4 7
4
2 3 8 9
-> 1 2 3 4 7 8 9
```

**要求**：用双指针归并（`i` 走第一个数组，`j` 走第二个），**不要先拼起来再排序**。

**提示**：谁的当前元素小就放谁，然后那个指针后移。**最后一定有一个数组先走完**，剩下的直接全抄过去——这一步最容易漏。

---

### 10. 次大值 ★★

**要求**：找数组中的第二大值（严格小于最大值）。

**样例输入/输出**
```
5
3 9 1 9 2  -> 次大值 3
3
5 5 5       -> 不存在
```

**要求**：**一次遍历**完成。

**提示**：两个变量 `max`、`second`。遇到比 `max` 大的，`second = max; max = a[i];`；遇到**严格小于 max 但大于 second** 的，更新 `second`。

**必须注意**：重复的最大值不能算次大（`9 9 3` 的次大是 3，不是 9）。

---

### 11. 移动零 ★★★

**要求**：把所有 0 移到数组末尾，**非零元素的相对顺序不变**。

**样例输入/输出**
```
5
0 1 0 3 12
-> 1 3 12 0 0
```

**要求**：原地操作。

**提示**：和第 6 题（删除元素）是同一个套路——先"把非零的挤到前面"，剩下的位置全部补 0。想通这一点，两题就是一道题。

---

### 12. 出现次数最多的元素 ★★★

**要求**：找出数组中出现次数最多的元素及其次数。若有多个并列，输出**第一次出现的那个**。

**样例输入/输出**
```
7
2 3 2 5 3 3 5
-> 3 出现 3 次
```

**提示**：双重循环计数。记录 `best_val`、`best_cnt`，只有**严格大于**才更新（这样并列时保留先出现的）。

**进阶**：如果元素范围是 0–100，用桶（`cnt[101]`）能降到 `O(n)`。比较两种写法。

---

### 13. 判断有序 ★

**要求**：判断数组是否严格递增 / 非递减 / 无序，输出三种之一。

**样例输入/输出**
```
1 3 5 7  -> 严格递增
1 3 3 7  -> 非递减
1 3 2 7  -> 无序
```

**提示**：用两个标志变量，或者一次遍历判断。**注意长度为 1 的数组两种情况都满足**。

---

### 14. 冒泡排序 ★★★

**要求**：实现冒泡排序（升序），并输出每一轮结束后的数组。

**样例输入/输出**
```
5
5 1 4 2 8
-> 第 1 轮: 1 4 2 5 8
-> 第 2 轮: 1 2 4 5 8
-> 第 3 轮: 1 2 4 5 8
...
```

**要求**：
1. 写出**标准版**（两层循环）
2. 加优化：如果某一轮没有发生交换，说明已经有序，**提前结束**
3. 统计比较次数和交换次数

**必须回答**：
1. 内层循环的上界为什么是 `n - 1 - i`？（每轮结束后，最后 `i` 个已经就位）
2. 最坏、最好情况各比较多少次？

---

### 15. 选择排序 ★★

**要求**：实现选择排序（升序）。

**提示**：每轮在未排序部分找最小值，和未排序部分的第一个元素交换。

**必须回答**：冒泡和选择，哪个交换次数少？为什么？**如果交换的代价很高**（比如元素是很大的结构体），该选哪个？

---

### 16. 插入排序 ★★★

**要求**：实现插入排序，并输出每一步的数组状态。

**样例输入/输出**
```
5
5 2 4 6 1
-> 第 1 步: 2 5 4 6 1
-> 第 2 步: 2 4 5 6 1
...
```

**提示**：把 `a[i]` 插到前面已排序的部分里。**和第 7 题（有序插入）是同一个动作**，只是重复执行。

**必须回答**：插入排序在什么情况下特别快？（提示：几乎有序的数组。）为什么？

### 18. 矩阵转置 ★★

**要求**：读入 `m×n` 矩阵，输出它的转置 `n×m`。

**样例输入/输出**
```
2 3
1 2 3
4 5 6
->
1 4
2 5
3 6
```

**要求**：先写"用另一个数组"的版本，再尝试**方阵原地转置**（只交换右上三角）。

**必须回答**：原地转置为什么只能对方阵做？内层循环的 `j` 应该从几开始？（从 `i+1`，只处理一半。）

---

### 19. 矩阵加法与乘法 ★★★

**要求**：分别实现矩阵加法和矩阵乘法。

```
加法：C[i][j] = A[i][j] + B[i][j]      （要求同型）
乘法：C[i][j] = Σ(k) A[i][k] * B[k][j] （要求 A 的列数 = B 的行数）
```

**样例输入/输出**
```
加法：
2 2
1 2
3 4
2 2
5 6
7 8
-> 6 8
   10 12

乘法：
2 3
1 2 3
4 5 6
3 2
7 8
9 10
11 12
-> 58 64
   139 154
```

**必须做到**：
1. 乘法前**先检查维度是否匹配**，不匹配就报错
2. 乘法的结果数组要**先清零**（`int c[100][100] = {0};`）

**必须回答**：矩阵乘法为什么是三重循环？`O(n³)` 是什么概念？—— 这是"算法复杂度"的第二次现身。

### 22. 对角线 ★★

**要求**：求方阵的主对角线元素之和、副对角线元素之和。

### 23. 上三角与对称矩阵 ★★★

**要求**：
1. 判断方阵是否为**上三角矩阵**（`i > j` 的位置全为 0）
2. 判断方阵是否为**对称矩阵**（`a[i][j] == a[j][i]`）

**样例输入/输出**
```
1 2 3
0 4 5
0 0 6
-> 是上三角

1 2 3
2 4 5
3 5 6
-> 是对称矩阵
```

**要求**：判断对称时只需检查一半（`j > i`），说明为什么。

### 24. 杨辉三角（数组版） ★★

**要求**：用二维数组输出前 `n` 行杨辉三角。

**样例输入/输出（n = 5）**
```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**提示**：`a[i][0] = 1`，`a[i][i] = 1`，中间 `a[i][j] = a[i-1][j-1] + a[i-1][j]`。

**必须做到**：
1. 数组**全部初始化为 0**（`int a[50][50] = {0};`）
2. 只输出 `j <= i` 的部分（下半三角）

**做完和第 03 章第 28 题（不用数组版）对比**：哪个更直观？哪个更省内存？

### 25. 鞍点 ★★★

**要求**：找出矩阵的鞍点（在所在行最大、所在列最小）。可能没有，也可能有多个。

**样例输入/输出**
```
3 3
1 2 3
4 5 6
7 8 9
-> 鞍点: 3 (第 0 行第 2 列)
```

**提示**：对每个元素，先判断它是不是本行最大，再判断是不是本列最小。**两个条件都要判**，是 `&&` 关系。

**注意**：如果有多个相等的最大值，这个定义会有歧义——先按"严格大于/小于"来写，并在注释里说明你的约定。

### 26. 矩阵旋转 ★★★

**要求**：把 `n×n` 方阵顺时针旋转 90°，输出结果。先写"用辅助数组"版，再挑战**原地**版。

**样例输入/输出**
```
3
1 2 3
4 5 6
7 8 9
->
7 4 1
8 5 2
9 6 3
```

**提示**：
- 辅助数组版：`b[j][n-1-i] = a[i][j]`
- 原地版：**先转置，再左右翻转每一行**。两句话就是答案。

**必须回答**：逆时针 90° 怎么做？（先转置，再上下翻转。）

## C 组 · 数组算法与模拟（27–32）

### 27. 二分查找 ★★★

**要求**：在**有序**数组中查找 `x`，返回下标（找不到返回 `-1`），并输出查找次数。

**样例输入/输出**
```
8
1 3 5 7 9 11 13 15
7
-> 下标 3，查找 2 次
30
-> 未找到
```

**要求**：写出 `while (low <= high)` 版本，并**手动模拟**一次查找过程。

**必须回答**：
1. 为什么是 `low <= high` 而不是 `low < high`？（`low == high` 时还剩一个元素没检查）
2. `mid = (low + high) / 2` 有什么隐患？怎么改？（`low + (high - low) / 2`，防止溢出）
3. 34 个元素最多查几次？（`log2(34)` 向上取整 = 6）

**这题是考试重点，务必手推一遍。**

---

### 28. 螺旋矩阵 ★★★

**要求**：输出 `n×n` 的螺旋矩阵（从 1 开始，顺时针向内填充）。

**样例输入/输出（n = 3）**
```
1 2 3
8 9 4
7 6 5
```

**提示**：维护四个边界 `top`、`bottom`、`left`、`right`，按"右→下→左→上"四步走，每走完一条边就收缩边界。

**必须注意**：每走一条边都要检查 `top <= bottom` / `left <= right`，否则 `n` 为奇数时中间会重复填充。

---

### 29. 数组模拟栈 ★★

**要求**：用数组实现一个栈，支持 `push`、`pop`、`top`、`isEmpty`、`isFull`。菜单驱动，循环操作直到用户选退出。

**交互样例**
```
1. push  2. pop  3. top  4. 退出
> 1 10
入栈 10
> 1 20
入栈 20
> 2
出栈 20
> 3
栈顶 10
> 2
出栈 10
> 2
栈为空
```

**提示**：一个数组 `int st[100]`，一个 `top` 下标（初始 `-1`）。`push` 是 `st[++top] = x`，`pop` 是 `return st[top--]`。

**必须回答**：`top = -1` 表示空栈，为什么不用 0？（用 0 的话 `st[0]` 到底是空还是有元素就说不清了。）

---

### 30. 数组模拟队列 ★★

**要求**：用数组实现循环队列，支持入队、出队、判空、判满。

**提示**：两个下标 `front`、`rear`，`rear = (rear + 1) % MAX`。为了区分"空"和"满"，可以**浪费一个格子**，或者额外记一个 `count`。

**必须回答**：为什么普通队列"出队后前面空出来的位置"不能再用？（因为 `front` 一直往后走。）循环队列解决了什么？

---

### 31. 计数排序 ★★★

**要求**：读入 `n` 个 0–100 的整数，用计数排序输出升序结果。

**样例输入/输出**
```
8
75 3 99 3 50 0 100 75
-> 0 3 3 50 75 75 99 100
```

**提示**：开一个 `cnt[101]` 计数，然后从小到大遍历桶，把每个值输出 `cnt[i]` 次。

**必须回答**：
1. 计数排序的时间复杂度是多少？（`O(n + k)`，`k` 是数值范围）
2. 如果数据是 `1 1000000000`，这个算法还能用吗？为什么？
3. 计数排序**稳定**吗？（想一下：如果有"值 + 附加信息"，还能保持原顺序吗？）

**这是"用空间换时间"的第一个例子**。以后学哈希表会再见到它。

### 32. 综合：成绩统计系统 ★★★

**要求**：读入 `n` 个学生的学号和三科成绩，完成：

1. 输出每个学生的总分和平均分
2. 按总分**降序**排序（总分相同按学号升序）
3. 输出每科的平均分、最高分、最低分
4. 输出总分高于全体平均分的学生人数

**样例输入/输出**
```
3
101 80 90 85
102 70 60 75
103 100 95 98
->
学号   总分   平均
103    293   97.7
101    255   85.0
102    205   68.3

语文平均 83.3，最高 100，最低 70
数学平均 81.7，最高 95，最低 60
英语平均 86.0，最高 98，最低 75

高于平均总分的有 1 人
```

**提示**：
1. 数据用一个 `int a[100][4]`（学号 + 三科）存也行，但**下一章学了结构体会舒服得多**
2. 排序时**整行一起交换**，不能只交换总分那一列
3. 排序规则是多关键字：先比总分，再比学号

**必须做到**：把"读入、统计、排序、输出"拆成四个函数（第 04 章学的）。

**这题是第 08、09、10 章的引子**：等你学了结构体和文件，同一个系统会重写三遍，每一遍都更清晰。

## 易错点速查

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `i <= n` | 越界，改坏别的变量 | `i < n` |
| 2 | 数组未初始化就累加 | 结果随机 | `= {0}` |
| 3 | `int n = 10; int a[n];` | 不是常量长度 | `#define N 10` |
| 4 | 函数里 `sizeof(a)/sizeof(a[0])` | 得 8/4 = 2 | 传 `n` |
| 5 | 二维数组省了第二维 | 编译错误 | `int g[][4]` |
| 6 | `a[5]` 对 `int a[5]` | 越界不报错 | 最大下标 4 |
| 7 | 删除元素后没更新 `n` | 后面越界/多输出 | `n = j` |
| 8 | 排序只交换一列 | 数据错位 | 整行/整条记录交换 |
| 9 | 二分用 `low < high` | 漏最后一个 | `low <= high` |
| 10 | 100 分 `score/10` | 下标 10 越界 | 单独处理 |
| 11 | 平均 `sum / n` | 整除丢小数 | `(double)sum / n` |
| 12 | 冒泡内层到 `n-1` | 越界 | `n-1-i` |

## 参考答案（仅分析题）

**第 2 题**：`i < j` 正确（每个元素只换一次）。`i <= n/2` 在 `n` 为偶数时会把中间两个换两次，等于没换回来；`i < n/2` 对偶数正确、对奇数会漏掉中间元素（但中间元素本来就不用动，所以也对）。**结论：`i < j` 是最不会出错的写法。**

**第 4 题**：100 分时 `100/10 = 10`，`cnt[10]` 越界（数组只开到 10 个，合法下标 0–9），会写到数组外面。

**第 19 题**：矩阵乘法三重循环，时间复杂度 `O(n³)`。1000×1000 的矩阵要 10 亿次乘法——这就是为什么 GPU 和矩阵库那么重要。
