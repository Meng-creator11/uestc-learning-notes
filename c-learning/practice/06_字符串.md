## 开始前：知识点自查

- [ ] 字符串**不是**一种类型，它是 `char` 数组 + 结尾的 `'\0'`
- [ ] `"hello"` 占 **6** 个字节，不是 5
- [ ] `sizeof(s)` 是数组总大小，`strlen(s)` 是实际字符数，两者完全不同
- [ ] `s = "hi"` 非法，要用 `strcpy`
- [ ] `s1 == s2` 比的是地址，要用 `strcmp(...) == 0`
- [ ] `scanf("%s", s)` 遇空格停、且**不加 `&`**；读整行用 `fgets`
- [ ] `strcmp` 返回 **0 才表示相等**（这是最容易记反的）

## A 组 · 本质与手写库函数（1–10）

### 1. 读程序：`sizeof` vs `strlen` ★

**要求**：先写出输出，再运行验证。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char a[] = "hello";
    char b[20] = "hello";
    char c[5] = {'h','e','l','l','o'};
    char d[] = "hi\0there";

    printf("%zu %zu\n", sizeof(a), strlen(a));
    printf("%zu %zu\n", sizeof(b), strlen(b));
    printf("%zu %zu\n", sizeof(c), strlen(c));
    printf("%zu %zu\n", sizeof(d), strlen(d));
    printf("%s\n", d);
    return 0;
}
```

**必须回答**：
1. 第一行是 `6 5`，为什么不是 `5 5`？
2. 第三行（`c`）的 `strlen` 结果为什么**不确定**？（`c` 没有 `'\0'`，`strlen` 会一直往后找，直到撞上内存里的某个 0——运气好是 5，运气不好是别的数，甚至可能崩）
3. 第四行 `sizeof(d)` 是 9，`strlen(d)` 是 2，`%s` 打印 `d` 为什么只出来 `hi`？（`\0` 就是结束标记，后面的 `"there"` 还在内存里，但 `%s` 不管）

**这题答对了，字符串你就入门了。**

### 3. 手写 `mystrcpy` ★★

**要求**：实现 `void mystrcpy(char dst[], const char src[])`，把 `src`（含 `'\0'`）复制到 `dst`。

**样例输入/输出**
```
src = "hello"

```

**必须做到**：
1. **必须把 `'\0'` 一起复制过去**（这步最容易漏）
2. 调用者负责保证 `dst` 足够大

**提示**：一次复制一个字符，`i` 一直走到 `'\0'` 并把它也拷过去，或者用"先赋值再判断"的写法。

**必须回答**：如果漏了 `'\0'`，`printf("%s", dst)` 会发生什么？（它会继续往后打印 `dst` 后面的垃圾，直到撞见 0。这就是"字符串没结尾"的经典现象。）

### 5. 手写 `mystrcmp` ★★

**要求**：实现 `int mystrcmp(const char a[], const char b[])`：相等返回 0，`a < b` 返回负数，`a > b` 返回正数。

**样例输入/输出**
```
"abc" "abc"  -> 0
"abc" "abd"  -> 负数
"abd" "abc"  -> 正数
"ab"  "abc"  -> 负数
```

**必须回答**：
1. 比较是按**字典序**逐字符比，第一个不同字符决定结果——"ab" 和 "abc" 为什么是"ab 更小"？
2. 返回**差值**（`a[i] - b[i]`）和返回 `-1/0/1` 有什么区别？哪种更常用？
3. 为什么库函数的约定是「0 表示相等」？（因为它原本返回的是"差值"，0 自然表示没差别）

### 8. 找 bug：字符串常见错误 ★★

**要求**：下面四段代码**都有问题**。逐个指出错误并修正。

```c
/* A */
char s[5] = "hello";
printf("%s\n", s);

/* B */
char s1[20], s2[20] = "hi";
s1 = s2;

/* C */
char s1[20] = "hi", s2[20] = "hi";
if (s1 == s2) printf("相等\n");

/* D */
char s[20];
scanf("%s", &s);
```

**提示**：
- A：`"hello"` 需要 6 个字节
- B：数组名是地址，不能整体赋值
- C：`==` 比的是地址
- D：`%s` 对应的是 `char*`，`&s` 类型是 `char (*)[20]`

**这四段是字符串 bug 的"四大名著"**，考试里换个壳反复考。

### 17. 手写 `mystrstr` ★★★

**要求**：实现 `char *mystrstr(const char s[], const char sub[])`，返回 `sub` 在 `s` 中**第一次出现**的位置（指针），找不到返回 `NULL`。

### 18. 字符串替换 ★★★

**要求**：把字符串中所有的 `old` 替换成 `new`（`new` 可以和 `old` 不等长）。

**样例输入/输出**
```
s = "I like cat, cat is cute"
old = "cat"
new = "dog"
-> I like dog, dog is cute
```

**要求**：用一个结果数组，**不许原地覆盖**（长度会变）。

**提示**：遍历 `s`，每次看当前位置是否匹配 `old`：匹配就复制 `new` 并跳过 `len(old)` 个字符；不匹配就复制一个字符继续。

**必须回答**：如果 `new` 比 `old` 长，结果数组要开多大？（最坏情况：每个字符都被替换成 `new`，所以 `strlen(s) / strlen(old) * strlen(new) + 1`。）

### 19. 字符串插入 ★★★

**要求**：在字符串的第 `pos` 个位置插入另一个字符串。

**样例输入/输出**
```
s = "helloworld", pos = 5, t = " "
-> "hello world"
```

**要求**：原地插入（把后面部分整体后移）。

**提示**：先从后往前搬（`s[i+len_t] = s[i]`），再从 `pos` 开始拷贝 `t`。**搬的时候要从末尾往前搬**，否则会覆盖还没搬的数据。

**这题和第 05 章第 7 题（有序插入）是同一个思想**：给新数据腾位置。

## 易错点速查

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `char s[5] = "hello";` | 没地方放 `'\0'` | 至少 `s[6]` |
| 2 | `s = "hi";` | 编译错误 | `strcpy(s, "hi")` |
| 3 | `if (s1 == s2)` | 比地址，恒不等 | `strcmp(s1,s2) == 0` |
| 4 | `strcmp` 返回 1 当相等 | 逻辑反了 | 0 才是相等 |
| 5 | 手工拼串忘 `'\0'` | 输出乱码 | 结尾补 `'\0'` |
| 6 | `fgets` 后不删 `'\n'` | 比较永远不等 | 手动置 `'\0'` |
| 7 | `scanf("%s", &s)` | 类型不对 | `scanf("%s", s)` |
| 8 | `strcpy` 目标太小 | 缓冲区溢出 | 先算长度 |
| 9 | 用 `%c` 读字符串 | 只读到第一个字符 | `%s` 或 `fgets` |
| 10 | 用 `strlen` 当循环条件 | `O(n²)` | 先存到变量里 |
| 11 | 压缩/替换忘处理末尾 | 最后一个字符丢失 | 循环外再结算一次 |
| 12 | 汉字用 `strlen` 算长度 | 得字节数不是字数 | UTF-8 一个汉字 3 字节 |
