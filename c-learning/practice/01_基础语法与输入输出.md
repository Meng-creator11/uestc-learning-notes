### 4. 不用第三个变量交换 ★★

## B 组 · 运算符与表达式（11–20）

### 11. 读程序写输出：自增自减 ★

**要求**：不要运行，先在纸上写出输出；写完再运行验证。

```c
#include <stdio.h>
int main(void)
{
    int i = 5, j, k;
    j = i++;
    k = ++i;
    printf("%d %d %d\n", i, j, k);

    i = 5;
    printf("%d\n", i++ + i++);
    printf("%d\n", i);

    i = 5;
    printf("%d\n", ++i + ++i);
    return 0;
}
```

**必须回答**：最后两行输出的值，在 **C 标准里其实是"未定义行为"**（同一个表达式里多次修改同一个变量）。你知道为什么教材上的"答案"和不同编译器跑出来的可能不一样吗？

> 这题的意义不是算对，而是让你知道：**别在一个表达式里对同一个变量又改又用。**

### 17. 位运算入门 ★★

## 易错点速查

| # | 写法 | 后果 | 正确写法 |
|---|---|---|---|
| 1 | `scanf("%f", &d)`（`d` 是 `double`） | 读出垃圾值 | `scanf("%lf", &d)` |
| 2 | `scanf("%d", n)` | 崩溃或随机值 | `scanf("%d", &n)` |
| 3 | `1/2` 想得到 0.5 | 得到 0 | `1.0/2` 或 `(double)a/b` |
| 4 | `%d` 后面接 `%c` | 读到换行符 | `" %c"`（前面加空格） |
| 5 | `0.1+0.2 == 0.3` | 永远假 | `fabs(a-b) < 1e-9` |
| 6 | `a == b` 比较浮点/字符串 | 结果不可靠 | 见第 4、6 条 |
| 7 | `printf("%d", 3.14)` | 输出乱码 | 格式符和类型必须匹配 |
| 8 | 宏 `#define SQ(x) x*x` | `SQ(2+3)` = 11 | `#define SQ(x) ((x)*(x))` |
| 9 | `int` 存 `13!` | 溢出成负数 | `long long` + `%lld` |
| 10 | 中文右对齐用 `%6s` | 对不齐 | 汉字按字节算，需特殊处理 |

- (4) A。`!5 = 0`，`0+3 = 3`，`3>2` 为 1，`4<3` 为 0，`1 && 0 = 0`
